# SmartCollab – Real-Time Collaborative Code Editor

SmartCollab is a real-time collaborative coding platform that allows multiple developers to write, edit, and run code together in shared rooms. It supports multi-language editing, AI assistance, live chat, collaborative whiteboards, and real-time synchronization powered by WebSockets.

---

## 🌐 Tech Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js (API)
- **Database:** Redis (real-time state), MongoDB (persistent storage)
- **AI Integration:** OpenAI APIs, Excalidraw (whiteboard)
- **Hosting:** Vercel / Heroku

---

## ✨ Features

- 🧑‍💻 **Real-Time Code Collaboration** – Multiple developers can edit the same code simultaneously.
- 🌍 **Multi-Language Support** – JavaScript, Python, Java, C++ with syntax highlighting via CodeMirror 6.
- 🤖 **AI Coding Assistant** – Explain code, debug errors, generate suggestions, and improve logic.
- ▶️ **Code Execution** – Run code directly inside the editor and view outputs instantly.
- 💬 **Live Chat** – Communicate with collaborators inside the same room.
- 🎨 **Collaborative Whiteboard** – Shared Excalidraw canvas for diagrams and design discussions.
- 📋 **Copy & Download Code** – Easily copy code to clipboard or download in multiple languages.
- 🔐 **Room-Based Collaboration** – Create unique rooms to work with specific participants.
- 👥 **Participant Presence** – Track active users with live join/leave notifications.
